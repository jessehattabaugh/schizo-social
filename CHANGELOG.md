# Change Log

## January 28th 2025

I have an idea for a project I want to build, and since I lost interest in the Fediverse but still have this domain and it's certificates paid for, I've decided to repurpose this repository as well.

The goal of this new application is to identify predictions about finanicial markets in news articles and allow users to track the accuracy of those predictions.

I lost faith in Architect since it hasn't seen development in months, but the domain and certs are in AWS and I still think it's the best cloud environment to work in. I'm going to build a AWS Cloud Development Kit application.

Minimum viable product is a static html page that installs a PWA. This will have a "share target" feature, so that when installed, devices can share links to it. Eventually the system will source news articles from feeds, but for now it will be a manual process. There will be fields that allow the user to enter the details of the predictions in the articles.

Later on these manual entries will be used to generate an embedding model that will automatically identify predictions in future articles. Eventaully there will be an interface for browsing the predictions and determining their accuracy. This will be used to create social media posts calling out accurate or inaccurate predictions.

If successful the goal is to provide users with a way to identify the most accurate sources of financial news in exchange for a subscription fee.
